\begin{frame}[t]{Same-Sex Marriage frequentist variance}

\centering

\begin{block}{Theorem \parencite{giordano:2026:mrplew} (informal):}
You can use the weights for frequentist variance as if MrP were linear
if (and only if) $\y_i$ is a sufficient statistic of the model.
\end{block}

$\tarcol{\surcol{\sqrt{\Nsur}} \muhat[\cal]}$\\
under re-sampling of survey data (keeping the target fixed)

    in misspecified models with many random effects!
